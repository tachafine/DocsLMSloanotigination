LoanOrigination.ca provides three levels of reporting and analytics: a standard report library for common operational and regulatory needs, a self-service report builder for custom queries, and an advanced analytics module for dashboards, forecasting, and external business intelligence integration. Use these tools to monitor portfolio health, track pipeline performance, and prepare submissions for regulators and funders.

## Standard Report Library

The Standard Report Library contains pre-built mandatory and operational reports available without configuration. These reports are ready to run and cover the most common lender needs.

| Report | Purpose |
| --- | --- |
| Portfolio status | Current loan balances, statuses, and counts by program, region, and officer |
| Delinquency and ageing | Arrears classification, days past due, and ageing buckets |
| Disbursement and repayment activity | Cash flow summary by period, including principal, interest, and fee allocation |
| Approval pipeline | Applications in progress, stage ageing, and cycle time metrics |
| Impact summaries | Aggregated jobs, sector, and region data for funder and board reporting |
| Regulatory submissions | Formatted data exports aligned to common Canadian regulatory templates |

To run a standard report, navigate to **Compliance > Reports > Standard Library**, select the report, set the date range and filters, and export to CSV, Excel, or PDF.

## Report Builder

The Report Builder lets you create custom reports without technical support. You select fields, apply filters, define grouping, add calculated fields, and schedule automatic generation and distribution.

<Steps>
  <Step title="Create a new report">
    Go to **Compliance > Reports > Report Builder** and select **New Report**.
  </Step>
  <Step title="Select fields">
    Choose from loan, borrower, payment, application, and compliance fields. Drag fields into the column order you want.
  </Step>
  <Step title="Apply filters and grouping">
    Add date ranges, status filters, program filters, and group by fields such as region or officer.
  </Step>
  <Step title="Add calculated fields">
    Build custom calculations such as debt service coverage, average loan size, or yield using the built-in formula editor.
  </Step>
  <Step title="Schedule and distribute">
    Set a schedule (daily, weekly, monthly, quarterly), choose recipients, and select export format (CSV, Excel, or PDF).
  </Step>
</Steps>

## Advanced Analytics

The Advanced Analytics module provides a custom dashboard builder, portfolio performance metrics, trend analysis, forecasting, and executive reporting templates. You can also export data for use in external business intelligence tools.

<Steps>
  <Step title="Open the dashboard builder">
    Navigate to **Compliance > Analytics > Dashboards** and select **New Dashboard**.
  </Step>
  <Step title="Add widgets">
    Choose from portfolio composition, vintage analysis, delinquency rates, concentration exposure, yield analysis, and forecast models. Position and resize widgets to fit your layout.
  </Step>
  <Step title="Apply filters">
    Set global filters for date range, program, region, or officer so the entire dashboard updates together.
  </Step>
  <Step title="Save and share">
    Name the dashboard, set visibility (private, team, or organisation), and export the underlying data for use in external BI tools if needed.
  </Step>
</Steps>

<Tip>
  Scheduled reports and dashboards can be distributed automatically by email. Set distribution lists per report so board members, funders, and compliance officers receive the right information on the right cadence.
</Tip>
