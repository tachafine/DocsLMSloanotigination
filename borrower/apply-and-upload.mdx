LoanOrigination.ca provides a guided application experience for borrowers through both the responsive web portal and the native mobile app. Applications support progressive disclosure, autosave of drafts, and seamless resumption across devices so applicants can start on one channel and finish on another.

## Application submission

The application workflow uses progressive disclosure to show relevant fields based on earlier answers. Inline validation and completeness checks help applicants submit accurate information before the application reaches the lender.

<Steps>
  <Step title="Start your application">
    Log in to the web portal or open the mobile app. Select the loan program you want to apply for. The system loads the configured application template for that program.
  </Step>
  <Step title="Complete the guided form">
    Answer questions in the order presented. The form reveals additional fields only when they apply to your situation. Required fields are marked clearly.
  </Step>
  <Step title="Save and continue">
    Use **Save and continue** to store progress at any time. Drafts autosave automatically. You can log out and resume later from any device without losing data.
  </Step>
  <Step title="Review and submit">
    Review the completeness check summary. Fix any flagged issues, then submit the application. You receive a confirmation and a reference number.
  </Step>
</Steps>

## Document upload

Applicants can attach supporting documents during or after application submission. The platform supports multi-file and multi-format uploads with status indicators so borrowers know when each document has been received.

| Channel | Upload method | Supported formats |
| --- | --- | --- |
| Web portal | Drag and drop | PDF, JPG, PNG, DOCX |
| Mobile app | Camera capture | PDF, JPG, PNG, DOCX |

Uploaded documents are categorised by document type, scanned for viruses, and transmitted with encryption. Borrowers see upload status indicators for each file.

## Authentication

Borrowers authenticate through the web portal or mobile app using one or more of the following methods:

- **Email and SMS one-time passcode** verification
- **PIN** entry
- **Biometric authentication** on supported mobile devices (optional)

Sessions time out automatically for security. Borrowers can manage trusted devices through device management settings.

<Tip>
  If you switch from the mobile app to the web portal, log in with the same credentials to resume your draft exactly where you left off.
</Tip>
